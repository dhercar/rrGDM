# Print method for summary.rrGDM objects

Print method for summary.rrGDM objects

## Usage

``` r
# S3 method for class 'summary.rrGDM'
print(x, digits = 4, ...)
```

## Arguments

- x:

  An object of class `summary.rrGDM`, as returned by
  [`summary.rrGDM`](https://dhercar.github.io/rrGDM/reference/summary.rrGDM.md).

- digits:

  Number of significant digits for test statistics, estimates and effect
  sizes. Default is 4.

- ...:

  Currently unused.

## Value

Invisibly returns `x`.
