# Print method for anova_rrGDM objects

Print method for anova_rrGDM objects

## Usage

``` r
# S3 method for class 'anova_rrGDM'
print(x, digits = 3, ...)
```

## Arguments

- x:

  An object of class `anova_rrGDM`, as returned by
  [`anova.rrGDM`](https://dhercar.github.io/rrGDM/reference/anova.rrGDM.md).

- digits:

  Number of decimal places for the Wald statistics. Default is 3.

- ...:

  Currently unused.

## Value

Invisibly returns `x`.
