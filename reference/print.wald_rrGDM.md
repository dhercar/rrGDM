# Print method for wald_rrGDM objects

Print method for wald_rrGDM objects

## Usage

``` r
# S3 method for class 'wald_rrGDM'
print(x, digits = 4, ...)
```

## Arguments

- x:

  An object of class `wald_rrGDM`, as returned by
  [`wald_test`](https://dhercar.github.io/rrGDM/reference/wald_test.md).

- digits:

  Number of significant digits for test statistics and effect sizes.
  Default is 4.

- ...:

  Currently unused.

## Value

Invisibly returns `x`.
