# rrGDM: Reduced Rank Generalised Dissimilarity Models

Fits generalised dissimilarity models in which the dissimilarities
between sites are modelled as distances in a low-dimensional latent
space, using Template Model Builder (TMB) for estimation. See
[`rrGDM`](https://dhercar.github.io/rrGDM/reference/rrGDM.md) to fit a
model.
